# 📌 Trendigo

Trendigo is a frontend website built using modern web technologies. This project is designed to showcase a user-friendly UI and seamless performance.

## 🚀 Tech Stack

- **React.js** - JavaScript library for building user interfaces
- **HTML5 & CSS3** - For structuring and styling the website
- **JavaScript (ES6+)** - Core programming language
- **Material-UI** - UI component library for React
- **Parcel** - Bundler for fast development and production builds
- **Redux** - State management

## 🛠️ Installation & Setup

Follow these steps to clone and run the project on your local system:

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Pooja-Mehra9921/Trendigo.git
cd trendigo


### 2️⃣ Install Dependencies
npm install

### 3️⃣ Run the Project
npx parcel index.html
```
